# Private review artifacts

Do not copy this directory to a web root, offline download or Nostr payload.

- source-data preserves original datasets byte-for-byte.
- claim-register accounts for all 6,730 scalar source fields: 57 retained, 3 corrected, 6,670 withheld.
- roster-approvals contains independent primary-source review recommendations, exact passages and the primary agent's passage-match check. Soi's rejection status is explicitly committee recommendation; the separate House rejection vote is not established by the local Hansard.
- release-approval hashes the exact approved public JSON projection.
- proposed-corrections and episode-corrected-review-only hold 596 source-backed repairs. These improve the research dataset but do not confer publication clearance.
- recovery-verification records local encrypted recovery only. Caroline has not received or independently recovered the key.

The scalars include metadata and repeated fields; these counts are not unique claims or factual-error counts. Every public substantive roster field has a retained/corrected decision. Withheld material is not evidence of misconduct or clearance.
